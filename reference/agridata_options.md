# Set or get options for agridata

Set or get options for agridata

## Usage

``` r
agridata_options(...)
```

## Arguments

- ...:

  Option names to retrieve option values or `[key]=[value]` pairs to set
  options.

## Value

the default and modified options.

The following options are supported

``` r
agridata_options()
```
