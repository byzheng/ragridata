# Download soil file from asris and convert to json which can be used in APSIM NG

Download soil file from asris and convert to json which can be used in
APSIM NG

## Usage

``` r
asris_soil(lon, lat, outfile, models = NULL)
```

## Arguments

- lon:

  longitude

- lat:

  latitude

- outfile:

  output file

- models:

  path to models. not required, if provided, the soil file will be
  upgraded to the latest version of APSIM NG.

## Value

No return values
